# CS50 Speller (C)

This project implements a dictionary-based spell checker in C.

## Features

- Load a dictionary into memory using hash tables
- Check words in a text file for spelling errors
- Count total words and misspelled words
- Efficient memory management with proper allocation and deallocation

## Description

The program reads a dictionary file and a text file, then outputs any misspelled words.  
It focuses on:

- Hash table implementation for fast word lookup
- Pointer manipulation and memory management
- Algorithm optimization for large text files

## Technologies

- C
- Hash tables
- File I/O
- Pointers and dynamic memory
